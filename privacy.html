Privacy

Privacy policy

Last updated: 2026-10-29

Summary

  • Account tokens are stored locally in the keyring of your operating system.
  • Nothing is sent to servers operated by the project.
  • The launcher has no telemetry, no analytics and no crash reporting.
  • Network requests go only to the services listed below.
  • Logs are uploaded only when you ask for it explicitly.

The data kept on the device

  • Microsoft and Minecraft tokens. The access and refresh tokens of the sign-in are kept in the system keyring: Windows Credential Manager, the macOS Keychain or the Secret Service on Linux. They are never written to a configuration file or a log.
  • The account profile. The Minecraft profile name, the UUID and the skin reference are stored locally to show the account.
  • The launcher data. Instances, settings, downloaded game files, mods and logs stay in the data directory of the launcher on your machine.
  • The launcher logs. The logs of the launcher mask tokens, keys and passwords.
  • Third-party API keys. A CurseForge API key that you supply is stored locally on the device.

Removing an account in the launcher deletes its tokens from the keyring. Uninstalling the launcher and deleting its data directory removes the rest of the local data.

The network requests

The launcher contacts the following services. Every request goes directly from your device to the service, under the privacy policy of that service.

The services the launcher contacts
ServicePurposeData sent
Microsoft identity platform The sign-in of the account The parameters of the sign-in and the refresh tokens. The credentials are entered on the pages of Microsoft itself.
Xbox Live The authentication of Xbox and the authorization of XSTS The Microsoft access token
Mojang and the Minecraft services The sign-in of Minecraft, the check of the ownership of the game, the profile, the skins, the lists of the game versions and the game files The Minecraft access token, the requests of the profile and of the skin
Modrinth The search and the download of mods and modpacks The search queries and the identifiers of the projects
CurseForge The search and the download of mods and modpacks, the identification of the installed files The search queries, the identifiers of the projects, the fingerprints (32-bit hashes) of the mod files and your own CurseForge API key
Adoptium The download of the Java runtimes The requested version of Java, the operating system and the architecture
mclo.gs The sharing of a log The content of a game log, only after you confirm the upload. The tokens, the keys and the passwords are masked.

Like every network request, these requests show the IP address of the device to the service that receives them.

Telemetry

The launcher collects no telemetry and does not track the use of it.

The sharing of data

The project receives no personal data and shares none. The data leaves the device only in the requests listed above.

Children

The launcher authenticates with Microsoft accounts. The rules of age and of parental consent for those accounts are set by Microsoft and Mojang.

The site itself

This website has no server behind it: it makes no request to any third party, embeds no tracker and no external font, and sets no cookie. The only link that leaves the page is the one to the releases on GitHub, and only when you choose it.

Contact

Questions about privacy: vibelauncher@vibefork.me. Problems with the launcher: the issues on GitHub.
