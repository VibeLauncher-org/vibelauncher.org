Download

Get VibeLauncher

Every package is published on the page of the releases. Pick the one for your system; the launcher updates itself afterwards.

Windows

vibelauncher-<version>-windows-x64.msi

No administrator rights. It installs for the current user into %LOCALAPPDATA%\Programs\VibeLauncher and adds itself to the Start menu.

A portable archive runs from any folder: vibelauncher-<version>-windows-x64-portable.zip.

Download for Windows

macOS

vibelauncher-<version>-macos-universal.dmg

One disk image for Apple silicon and Intel Macs, macOS 11 (Big Sur) or newer. Drag the app into Applications.

Signed ad hoc and not notarized, so Gatekeeper asks twice: Done, then System Settings > Privacy & Security > Security > Open Anyway.

Download for macOS

Linux

tar.gz · AppImage · .deb · .rpm

The archive runs from any folder; the AppImage needs no installation; the .deb and the .rpm install into the system.

Download for Linux

The first start

The releases are not signed with a code signing certificate, so the system asks before the first run.

Windows: "Windows protected your PC"

SmartScreen may stop a file that is not signed. Choose More info, then Run anyway. The updates that VibeLauncher installs itself are not marked as downloaded.

macOS: "VibeLauncher cannot be opened"

Gatekeeper asks twice: choose Done, then System Settings > Privacy & Security > Security > Open Anyway. On macOS 14 and older: Control-click the app in Finder and choose Open.

Where do the packages come from?

All of them are on the page of the releases, together with the checksums. The launcher itself updates from there.
